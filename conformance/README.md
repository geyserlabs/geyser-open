# Public developer conformance

The public suite freezes protocol/core, emulator, extension, packaging, and malicious-input cases.
Receipts bind the exact SDK/CLI version, schema version, Python/OS tuple, fixture digest, and test
result. A passing receipt is expiring technical evidence; it is not enrollment, authority, policy,
or a security warranty.

The broader runtime/provider/model/placement matrix is generated by the private fleet
qualification system. Public fixtures contain no customer content or credentials.
