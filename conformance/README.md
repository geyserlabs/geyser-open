# Public developer conformance

The public suite freezes protocol/core, runtime-adapter, provider-transport, model-delta,
placement/privacy, developer-artifact, emulator, extension, packaging, and malicious-input cases.
Receipts bind the exact SDK/CLI or runtime version, immutable bytes, source commit, provider,
model profile, placement, privacy posture, Python/OS/architecture tuple, fixture evidence, and
expiry. A passing receipt is technical evidence; it is not enrollment, authority, policy, or a
security warranty.

`conformance.qualification.capability_matrix` accepts only complete, canonically bound, unexpired
receipts. Its capability rows are derived from assertions that cite passing frozen cases. Missing
layers remain visibly unqualified, and contradictory evidence fails closed.

The broader runtime/provider/model/placement matrix is generated by the private fleet
qualification system. Public fixtures contain no customer content or credentials.
